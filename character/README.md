# ② 캐릭터 만들기 (`character/`)

`characters.json`(①)의 선수 6명을 기본으로 쓰고, 사용자가 스탯을 직접 나눠 만든 커스텀 1명을 더해 **총 7명**의 캐릭터와 이미지를 만든다.

## 바로 보기
배포된 사이트에서 `/character/` 로 열면 저장소 맨 위 `characters.json`(①)을 직접 읽는다. `index.html`을 더블클릭해서 열면(file://) 내장 사본 `data/characters.js`를 쓴다.

## 폴더 구성
| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 로스터 화면 + 커스텀 캐릭터 만들기 화면 |
| `art.js` | **이미지 생성기.** 스탯을 넣으면 캐릭터 SVG가 나온다 (브라우저·Node 모두 동작) |
| `../characters.json` | ①이 만든 원본 (이 폴더에는 복사하지 않음) |
| `data/characters.js` | 원본을 file:// 에서도 읽게 감싼 사본 (자동 생성) |
| `data/characters_7.json` | 6명 + 커스텀 예시 1명. `specialAbility`, `look`(2D 겉모습), `title`(칭호), `image` 경로 포함. 커스텀에는 `appearance`(fight 형식)도 포함 |
| `images/*.png` | 7명 이미지, 870×960 투명 PNG (`custom.png`는 예시 "철벽 복서") |
| `images/*.svg` | 같은 이미지의 SVG (크기를 키워도 깨지지 않음) |
| `tools/export-images.js` | `node tools/export-images.js` → SVG와 JSON을 다시 생성 |
| `tools/selftest.html` | 자동 테스트 21개 (`/character/tools/selftest.html`을 서버로 열기) |

## 커스텀 캐릭터 규칙
- 선수 6명의 스탯 합이 **모두 49점**이다. 그래서 커스텀도 **49점을 7개 스탯에 나눠야** 저장된다. 스탯 하나는 1~10점.
- 시작점은 "균형형(전부 7점)"이나 선수 6명 중 한 명의 스탯 중에서 고른다.
- 랜덤 버튼을 눌러도 항상 합계 49점이 된다.
- 종목 스타일(7종), 유니폼 색(9색), 머리 모양(6종)을 고른다.
- 칭호는 높은 스탯 두 개로 자동으로 정해진다. 예: 오타니 = 롱리치 파괴자, 은가누 = 한방 탱커.
- "가장 닮은 선수"를 레이더 차트의 점선으로 비교해 보여준다.
- **특수 능력**은 선수 6명의 능력 중 하나를 고른다. 따로 고르지 않으면 가장 닮은 선수의 능력이 들어간다.
- 저장하면 로스터 7번째 칸에 들어가고, 브라우저(localStorage `jeck.customCharacter.v1`)에 남는다.
- `fight/`가 읽는 **`appearance`**는 자동으로 계산된다. 키 `heightCm`는 사거리, 체형 `build`는 맷집과 파워, 파이팅 스타일 `style`은 가장 높은 스탯(격투기를 고르면 킥복서)으로 정한다. 색 `color`는 유니폼 색을 쓴다.

## 이미지가 스탯을 반영하는 방식
| 스탯 | 그림에서 바뀌는 것 |
|---|---|
| 사거리 | 키, 다리 길이, 뻗은 팔 길이 |
| 맷집 + 파워 | 몸통 폭, 팔다리 두께 |
| 이동 속도 | 다리가 가늘어짐. 9 이상이면 발밑에 속도선 |
| 파워 9 이상 | 뻗은 주먹에 폭발 이펙트 |
| 공격 속도 8 이상 | 팔 주변에 잔상선 |
| 방어 8 이상 | 가드 쪽에 육각 실드 |
| 체력 9 이상 | 몸 주위에 에너지 오라 |

선수는 실제 얼굴을 닮게 그리지 않았다. 종목 소품(야구 모자와 배트, 축구공, 배구공, 농구공, 수모와 수경, MMA 글러브)으로만 구분한다.

## ③ 싸움 계산 · ④ 3D 렌더링에서 쓰는 법
- **데이터:** "7명 JSON 받기" 버튼으로 받은 `characters_7.json`을 쓰면 된다. `stats`는 ①의 형식과 똑같다. 커스텀에는 `"custom": true`가 붙는다.
- **같은 페이지 안에서 쓸 때:**
  ```js
  window.Roster.list()            // 7명 배열 (커스텀이 저장돼 있으면 포함)
  CharacterArt.render(character)  // 캐릭터 SVG 문자열
  CharacterArt.radar(stats, color)
  ```
- **이미지:** `images/{id}.png`. 커스텀은 화면의 "이미지(PNG) 받기" 버튼으로 받을 수 있다.

## ①이 스탯을 수정했을 때
배포된 화면은 자동으로 반영된다. 이미지 파일과 내장 사본을 갱신하려면 아래 명령을 실행한다.
```
node tools/export-images.js
```
PNG까지 새로 만들려면 화면의 "전체 이미지 받기" 버튼을 쓰면 된다.
